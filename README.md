# Messenger

Веб-приложение мессенджера

## Демо

https://messengersprinte.netlify.app/

## Описание

Одностраничное приложение (SPA) с клиентским роутингом. Интерфейс собирается из
переиспользуемых компонентов на Handlebars, стили — на SCSS по методологии БЭМ.
Сборка и dev-сервер — Vite.

Формы проверяются на `blur` и повторно при `submit`. Для входа, регистрации,
профиля и смены пароля используются общие регулярные выражения.
Подтверждение пароля должно совпадать с новым паролем.
Невалидные формы не отправляются, валидные выводят объект заполненных полей в консоль.

Сообщения можно отправлять кнопкой Send или Enter. Пустые сообщения отклоняются.
Профиль и сообщения хранятся в памяти до перезагрузки страницы; серверного API,
реальной авторизации, смены пароля и загрузки аватара пока нет.

## Архитектура

- `src/components` — представления на основе типизированного `Block`.
  Формы и диалог монтируются через `mount`, обновляются через `setProps`
  и освобождают обработчики при `unmount`.
- `src/pages` — страницы, наследующие `Block` через базовый `Page`,
  шаблоны и локальные контроллеры в `helper.ts`. `Page` освобождает дочерние
  компоненты при обновлении и удалении страницы.
- `src/models` — модели профиля и переписки, независимые от DOM.
- `src/components/form/validation.ts` — общие правила проверки полей.
- `src/router` — клиентская навигация с очисткой предыдущей страницы.

## Технологии

- **TypeScript** — логика и типизация компонентов
- **Handlebars** — шаблоны (`.hbs`)
- **SCSS** — стили по методологии БЭМ
- **Vite** — сборка и dev-сервер
- **Netlify** — хостинг
- **ESLint**, **Stylelint**, **tsc --noEmit** — качество кода и проверка типов

## Страницы

- `/login` — вход
- `/registration` — регистрация
- `/main` — список чатов и переписка
- `/profile` — профиль
- `/edit-profile` — настройки профиля
- `/change-password` — смена пароля
- `/error?code=404` — страница ошибки

Неизвестные маршруты перенаправляются на страницу ошибки. Для прямого открытия
страниц на Netlify используется SPA fallback из `public/_redirects`.

## Команды

```bash
npm ci             # установка зафиксированных зависимостей
npm run dev        # dev-сервер на http://localhost:3000
npm run start      # сборка и запуск production preview на порте 3000
npm run build      # проверка типов и сборка в dist
npm run preview    # запуск уже собранной версии на порте 3000
npm run lint       # ESLint + Stylelint + TypeScript
npm run typecheck  # tsc --noEmit
```

Для запуска нужен Node.js 22.13+ (или совместимая актуальная LTS-версия).
Если порт 3000 занят, сервер завершится с ошибкой, а не выберет другой порт.

## Проверка и публикация

GitHub Actions запускает линтеры и сборку для pull request в `main`,
а затем автотесты Практикума. Собственные тестовые библиотеки не подключены.
Настройки форматирования редактора находятся в `.editorconfig`.
Рабочая ветка спринта — `sprint_2`.
Сгенерированные файлы `dist` и зависимости `node_modules` не коммитятся.

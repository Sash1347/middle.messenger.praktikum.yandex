# Messenger

Веб-приложение мессенджера

## Описание

Одностраничное приложение (SPA) с клиентским роутингом. Интерфейс собирается из
переиспользуемых компонентов на Handlebars, стили — на SCSS по методологии БЭМ.
Сборка и dev-сервер — Vite.

## Технологии

- **TypeScript** — логика и типизация компонентов
- **Handlebars** — шаблоны (`.hbs`)
- **SCSS** — стили по методологии БЭМ
- **Vite** — сборка и dev-сервер
- **Netlify** — хостинг

## Страницы

- `/login` — вход
- `/registration` — регистрация
- `/main` — список чатов и переписка

## Команды

```bash
npm install     # установка зависимостей
npm run dev     # запуск dev-сервера (http://localhost:3000)
```
